# 이준호 AX 포트폴리오

React + Vite로 제작한 GitHub Pages 정적 사이트. 사이트 경로는 `/portfolio/`다.

```sh
npm ci
npm run dev
npm run build
```

빌드 결과는 저장소의 `portfolio/`에 생성한다. 기존 루트 페이지, 앱 소개, 광고·검색 소유권 인증 파일은 수정하지 않는다. 배포는 기존 Pages의 `main` 브랜치 루트 설정을 사용한다.

프로젝트 구현 사례는 확인 가능한 적용 범위와 기간을 함께 표기한다. 후보 검토 화면은 실제 컴포넌트에 가상 데이터를 넣은 데모이며, 공개 자료에 회사 내부 설정·거래처 정보·private 프로젝트 코드를 포함하지 않는다.

폰트는 함께 제공된 SIL Open Font License에 따라 self-host한다. 표지 이미지의 제작 지시는 `ART_DIRECTION.md`에 기록한다.
