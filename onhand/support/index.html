English

How do I add a file?

In Files, Photos, Mail, or another app, open the Share Sheet and choose PocketTap. You can also tap + in PocketTap and choose a file. The saved copy will appear in Home and supported widgets.

How do I add a widget?

Touch and hold the Home Screen, choose Edit, then Add Widget, and search for PocketTap. Choose Automatic Files, the first option, to follow Home order and include new files automatically. File Desktop lets you select specific files through Edit Widget.

Small (2 files) and Medium (4 files) are free. PocketTap Pro unlocks Large (8 files) and Portrait XL (16 files on iOS 27 or later). The Widgets tab explains the available sizes.

A new file has not appeared in the widget

Widget updates are scheduled by iOS. Open PocketTap once to confirm the file was saved, then return to the Home Screen. The app requests a widget refresh after changes, but the system controls the exact refresh time.

How do I restore PocketTap Pro?

Open PocketTap, go to Settings, and choose Restore Purchase. Use the same Apple Account that originally purchased PocketTap Pro.

What should I include in a support request?

Please include your device model, iOS version, the file type involved, and the steps that led to the problem. Do not attach private files unless they are necessary and safe to share.

한국어

파일을 어떻게 추가하나요?

파일, 사진, Mail 또는 다른 앱에서 공유 시트를 열고 포켓탭을 선택하세요. 포켓탭의 + 버튼으로 파일을 고를 수도 있습니다. 저장된 사본은 홈과 지원되는 위젯에 표시됩니다.

위젯을 어떻게 추가하나요?

홈 화면을 길게 누르고 편집 → 위젯 추가를 선택한 다음 포켓탭을 검색하세요. 첫 번째 옵션인 자동 파일 목록을 추가하면 홈의 파일 순서와 새 파일이 자동으로 반영됩니다. 파일 데스크톱은 위젯 편집에서 원하는 파일을 직접 선택하는 옵션입니다.

소형(파일 2개)과 중형(파일 4개)은 무료입니다. 포켓탭 Pro에서는 대형(파일 8개)과 iOS 27 이상에서 제공되는 세로형 XL(파일 16개)을 사용할 수 있습니다. 크기별 안내는 위젯 탭에서 확인하세요.

새 파일이 위젯에 바로 나타나지 않아요

위젯 갱신 시점은 iOS가 관리합니다. 포켓탭을 한 번 열어 파일 저장을 확인한 뒤 홈 화면으로 돌아가세요. 포켓탭은 변경 후 위젯 갱신을 요청하지만 정확한 반영 시점은 시스템이 결정합니다.

포켓탭 Pro를 어떻게 복원하나요?

포켓탭의 설정 탭에서 구매 복원을 누르세요. 처음 포켓탭 Pro를 구매한 Apple 계정을 사용해야 합니다.

지원 요청에는 무엇을 적어야 하나요?

기기 모델, iOS 버전, 관련 파일 형식과 문제가 발생한 순서를 알려주세요. 필요하고 안전한 경우가 아니라면 개인 파일을 첨부하지 마세요.
